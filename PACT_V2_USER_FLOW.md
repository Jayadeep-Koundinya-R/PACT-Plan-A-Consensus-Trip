# PACT - End-to-End User Flow

1. **Front Door:** Landing Page -> User Logs In (Google/Email).
2. **Dashboard:** Clean empty state -> Clicks "+ Plan a New PACT".
3. **Creation Wizard:** Enters Title -> Selects Global Currency -> Sets Destination Options -> App routes to Circle Hub.
4. **Circle Hub (Phase 1: Voting):** Users submit budgets/dates. What-If slider available. Chat active.
5. **Consensus Climax:** Supermajority hit -> Wax Seal drops -> Golden Boarding Pass generated.
6. **Circle Hub (Phase 2: Active Trip):** UI transforms into "Living Manifest" (Transport + AI Spots).
7. **Circle Hub (Phase 3: Post-Trip):** UI shifts to "Vault/Memories" gallery for photo uploads.
